Bitaxe Tuner

Steps frequency and core voltage up in small increments, tests each point, and tells you which settings are actually stable.

Overclocking can damage hardware. Every point is held to hard limits (ASIC temp, VR temp, power, input voltage) and the miner's original settings are restored when a run ends, is stopped, or this app restarts. Set the limits below to match your board and power supply. Make sure your fan and cooling are working before you start. A run takes a while; leave the miner alone while it works.
