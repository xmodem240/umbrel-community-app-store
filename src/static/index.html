Bitaxe Tuner

Steps frequency and core voltage up in small increments, tests each point, and tells you which settings are actually stable.

Overclocking can damage hardware. Every point is held to hard limits (ASIC temp, VR temp, power, input voltage) and the miner's original settings are restored when a run ends, is stopped, or this app restarts. Set the limits below to match your board and power supply, and make sure your fan and cooling work before you start. The red Emergency stop button appears at the top while a run is active.
